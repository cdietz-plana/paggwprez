# GGW AI 101: interactive deck

Single self-contained `index.html` (fonts, images and encrypted slides inline). Password: **PlanA** (not case-sensitive).

## Host on GitHub Pages
1. Create a repository (public is fine: the slide content is encrypted in the file).
2. Upload `index.html` (and this README if you like) to the root of the `main` branch.
3. Settings > Pages > Build and deployment > Source: *Deploy from a branch*, Branch: `main` / `(root)`, Save.
4. The deck is live at `https://<your-account>.github.io/<repo>/` within a minute or two.

It also works opened straight from disk (double-click `index.html`).

## Presenting
- Next: click (right three quarters of the screen), Right arrow, Space, Page Down
- Back: click the left quarter, Left arrow, Page Up
- Home / End: first / last slide
- F: fullscreen
- Swipe left / right on touch screens
- `#12` at the end of the URL opens slide 12

Each click reveals the next card, column or row; when a slide is fully built, the next click moves on.
